# Mathematica Code Development Workspace Instructions

This workspace is designed for Mathematica code development with proper syntax checking, structure validation, and troubleshooting capabilities.

## Project Structure
- `notebooks/` - Mathematica notebook files (.nb)
- `src/` - Mathematica source code (.m files)
- `functions/` - Reusable Mathematica functions
- `modules/` - Mathematica packages and modules
- `tests/` - Test files and validation scripts
- `docs/` - Documentation and usage guides
- `examples/` - Example code and demonstrations
- `tools/` - Syntax checking and validation utilities

## Coding Standards
- Use proper Mathematica syntax and naming conventions
- Include comprehensive documentation for all functions
- Follow modular programming practices
- Implement error handling and validation
- Use meaningful variable and function names

## Syntax Validation
- All code should be syntactically correct before committing
- Use proper Mathematica formatting and indentation
- Validate function signatures and return types
- Check for common copy-paste issues and encoding problems

## Troubleshooting Guidelines
- Check for invisible characters and encoding issues
- Validate bracket matching and syntax structure
- Test functions with sample inputs
- Document known issues and solutions
